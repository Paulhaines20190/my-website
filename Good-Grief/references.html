Bootstrap migration

This version uses Bootstrap 5.3.8 for navigation, cards, buttons and form controls. Original CSS supplies mobile-first content grids, editorial layouts and the Peanuts visual theme. Native dialogs and existing API and quiz logic are retained.

Bootstrap documentation · Bootstrap MIT licence

Original CSS layout edition

Seven HTML pages, styles.css, bootstrap.min.css and app.js make up this ten-file website. bootstrap.min.css contains the vendor framework; styles.css contains original layouts and theme. app.js contains the JavaScript libraries, reusable application functions and the service worker. All libraries are included locally. Basic navigation remains available without JavaScript.

Upload all ten files together to GitHub Pages. No Python or build step is needed. Native dialogs, cached API results and matching-edition cover recovery are retained. Framework licence notices are included in app.js.

Architecture / how it connects

Technical map

A static, ten-file website. The browser renders the pages, runs the interactions and requests public API data. No application server or database is required.

Page responsibilities

index.html
Home page, theme tabs and image gallery.
characters.html
Character search and filtering, profile dialogs and saved favourite.
villains.html
Rival categories and expandable case notes.
quiz.html
Validated quiz steps, progress and character result.
books.html
API search, catalogue sorting and pagination, covers and book details.
advice.html
Validated topic, message and checkbox form with browser-generated advice.
references.html
Learning sources, framework attribution and this technical map.

Example: finding a book

Enter a title → validate the search → request Open Library JSON → render book cards → load cover images. Selecting a book requests its work details and opens a dialog. Failed requests show feedback and may use a previously saved response.
