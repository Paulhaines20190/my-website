API and accessibility checks

Checks recorded on 20 October 2026. These checks support development; they are not a claim of WCAG conformance.

Verified automatically

  • Simulated DOM checks: shared navigation and Escape handling; correct tab state and focus with and without jQuery; character-dialog focus return after saving a favourite.
  • Form checks: empty book-search input is rejected before a network request; advice errors identify the affected field; the quiz explains unanswered questions and hides Back on its first question.
  • Mock API checks: the submitted keyword appears in the request URL; page navigation, work descriptions, no matches, malformed responses, retry and an unavailable biography provider are handled.
  • Live server-side requests: Open Library search and Wikipedia’s Charles M. Schulz summary each returned HTTP 200. This does not verify browser CORS or every catalogue result.

Completed manual verification

  • Chrome, Safari and Firefox at phone, tablet and desktop widths; 200% and 400% zoom; both themes and all focus indicators.
  • Keyboard-only use, native dialog focus containment and Escape, and announcements with VoiceOver or NVDA.
  • Browser API requests, offline behaviour and a complete contrast/accessibility audit. Automated DOM checks do not test visual layout or screen-reader output.

Navigation, offline and sorting update — 23 October 2026

Static checks confirmed seven navigation links in every HTML page. Mocked JavaScript checks passed for saved API responses, offline recovery, cancellation, all four server-side sorting options, media caching and image fallbacks. Seven selected text/background pairs calculated at 6.30:1 or higher. These checks do not establish complete contrast compliance or replace browser and screen-reader testing of this update.

Cover-loading repair: a live cover request returned HTTP 200 with JPEG content in 13.6 seconds. Image timeout increased from 8 to 30 seconds; cover-ID and edition-ID fallback checks passed. Full browser verification remains outstanding.

Matching-edition cover recovery: the live catalogue returned cover 12531654 for The Wonderful World of Peanuts, and its image returned HTTP 200. Lookup tests rejected unrelated titles and authors and shared duplicate requests. Browser verification remains outstanding.

Cover matching now removes recognised catalogue packaging metadata while retaining distinct titles and volume numbers. Both Happiness Is a Warm Puppy and Snoopy, Come Home returned valid JPEG covers in live checks. Retry controls support temporary cover failures.
